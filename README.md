# PMLDL Assignment 1: Deployment

Automated MLOps pipeline: data engineering → model engineering → deployment
(FastAPI model API + Streamlit app, both in Docker containers). Predicts
whether a person likely has a sleep disorder (Healthy / Insomnia / Sleep
Apnea) from lifestyle and health metrics.

Dataset: [Sleep Health and Lifestyle Dataset](https://www.kaggle.com/datasets/uom190346a/sleep-health-and-lifestyle-dataset) (374 rows, CC0), included in `data/raw/`.

## Repository structure

```
code/
  datasets/prepare.py       # Stage 1: data engineering
  models/train.py           # Stage 2: model engineering
  deployment/
    api/                    # FastAPI model API + Dockerfile
    app/                    # Streamlit app + Dockerfile
    docker-compose.yml
data/
  raw/                      # raw CSV
  processed/                # train/test splits, generated by prepare.py
models/                     # trained model + metrics.json, generated by train.py
run_pipeline.py             # runs stages 1 -> 2 -> 3 once
scheduler.py                # runs run_pipeline.py every 5 minutes
requirements.txt
```

## Setup

```bash
python -m venv venv
source venv/bin/activate       # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Docker (with Compose v2) must also be installed and running.

## Run the pipeline once

```bash
python run_pipeline.py
```

This runs, in order:
1. `code/datasets/prepare.py` — loads `data/raw/sleep_health_and_lifestyle_dataset.csv`, cleans it (dedup, imputes missing `Sleep Disorder` as "Healthy", normalizes the "Normal Weight"/"Normal" BMI labels, drops Heart Rate outliers via IQR), splits into `data/processed/train.csv` and `test.csv`.
2. `code/models/train.py` — builds features (encodes Gender/BMI, splits Blood Pressure into systolic/diastolic), trains a RandomForestClassifier, evaluates it, saves `models/model.joblib` and `models/metrics.json`.
3. `docker compose ... up --build -d` — rebuilds the API and app images (picking up the freshly trained model) and (re)starts both containers.

## Run continuously (every 5 minutes)

```bash
python scheduler.py
```

Leave this running in a terminal. It calls `run_pipeline.py` every 5 minutes; if one run takes longer than that, the next run starts right after it finishes rather than overlapping — increase `INTERVAL_SECONDS` in `scheduler.py` if that happens regularly.
